# יוסי והצ'ולנט האבוד

משחק פלטפורמה מצחיק בסגנון סופר מריו. יוסי רץ, קופץ ורודף אחרי סיר צ'ולנט שברח לפני שבת.

משחקים כאן: https://yontanbe.github.io/cholent-dash/

## מה יש בפנים
- 9 שלבים: השכונה, השוק, האולם, החוף, מירון, בית המדרש, נמל התעופה, ענני שבת, והגג עם הבוס
- ארבע צורות כוח: יוסי, הרב, הרב הגדול והשחור יותר, והרב עם זקן ומשקפי שמש. כל צ'ולנט מעלה צורה, כל פגיעה מורידה צורה
- מנוע דמות עם עצמות (js/rig.js): ריצה, קפיצה, נפילה, פגיעה וחגיגה, הכל מחושב בקוד ולא מתחלף בין תמונות
- קפיצים, להבות שאי אפשר לקפוץ עליהן, פלטפורמות עננים
- מוזיקה שנוצרת בקוד (הבה נגילה). אפשר להוסיף קבצי mp3 בתיקיית music והם ינוגנו אוטומטית

## שליטה
חצים לזוז, רווח לקפוץ, Shift לרוץ, X לזרוק חלה (מהצורה הראשונה של הרב), M להשתקה, P להפסקה
